# Script de Demo - 30 minutos

## Antes de la demo

- Pedir datos reales del prospecto (nombre de liga, cantidad de equipos)
- Cargar una liga de prueba con esos datos
- Preparar 3 escenarios impactantes

## Estructura (30 min)

### Minuto 0-3 - Apertura
"Antes de mostrarte el sistema, cuentame: cuanto tiempo dedicas a administrar tu liga cada semana?"

(Escuchar. Anotar cifras.)

### Minuto 3-8 - El problema
"Te voy a mostrar como resolvemos los 3 problemas que mas nos mencionan los duenos de ligas:
1. Equipos que no pagan
2. Sanciones que generan conflicto
3. Falta de tiempo"

### Minuto 8-25 - Demo en vivo

**Escenario 1 (5 min) - Equipo moroso**
- Mostrar panel del admin con alerta de pago vencido
- Mostrar como el sistema bloquea alineacion automaticamente
- Mostrar como se ejecuta la fianza

**Escenario 2 (5 min) - Acta digital**
- Abrir acta desde el movil
- Escanear QR de un jugador
- Mostrar como se valida elegibilidad
- Registrar un gol y una tarjeta
- Cerrar acta

**Escenario 3 (5 min) - Sancion automatica**
- Mostrar como el sistema aplica suspension por acumulacion
- Mostrar notificacion al jugador y equipo
- Mostrar como se refleja en elegibilidad

**Escenario 4 (2 min) - Link publico**
- Abrir el link publico de la liga
- Mostrar tabla, goleadores, calendario

### Minuto 25-30 - Cierre

"Que te parecio? Que preguntas tienes?"

"Te propongo 30 dias gratis, sin tarjeta, con tu liga real. Si no funciona, no pagas."

## Objeciones comunes

**"Es caro"**
"Cuanto pierdes al mes por equipos morosos? Si recuperas aunque sea un 20%, se paga solo."

**"Ya tengo Excel"**
"Excel no bloquea alineacion, no cobra solo, no aplica sanciones. Este sistema si."

**"Mis equipos no van a querer"**
"Los equipos ganan: ven su tabla, sus stats, su carnet. Es mas facil para ellos."

**"No se usar tecnologia"**
"Esta disenado para usarse desde el celular. Te acompanamos en el onboarding."

## Despues de la demo

- Enviar one-pager por WhatsApp
- Enviar link de prueba
- Agendar seguimiento en 48 horas

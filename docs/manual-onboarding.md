# Manual de Onboarding de Ligas

## 1. Proposito

Definir el proceso paso a paso para activar una nueva liga en el SaaS, desde la firma del contrato hasta la operacion completa. Objetivo: activar una liga en menos de 5 dias habiles.

## 2. Perfiles involucrados

- Onboarding Manager: responsable del proceso completo.
- Soporte tecnico: resuelve dudas tecnicas.
- Admin de liga: contacto principal del cliente.
- Delegados: usuarios que operaran equipos.

En fase 1 (primeros 20 clientes), el fundador hace los 3 primeros roles.

## 3. Fases del Onboarding

### Fase 0 - Preventa (dia -7 a 0)
- Firma de contrato.
- Cobro de primer mes.
- Recoleccion de datos iniciales.

### Fase 1 - Configuracion (dia 1-2)
- Crear organizacion.
- Crear complejo.
- Crear liga.
- Configurar reglas.

### Fase 2 - Carga de datos (dia 3)
- Carga de equipos.
- Carga de jugadores.
- Carga de canchas y slots.

### Fase 3 - Capacitacion (dia 4)
- Sesion con admin de liga (60 min).
- Sesion con delegados (60 min).
- Sesion con arbitros (60 min).

### Fase 4 - Operacion asistida (dia 5-30)
- Primer torneo en paralelo.
- Soporte prioritario.
- Revision semanal.
- Ajustes segun feedback.

### Fase 5 - Handoff (dia 30)
- Entrega de manuales.
- Transferencia a soporte regular.
- Cierre del onboarding.

## 5. Guion de Primera Llamada

### Objetivo
Conocer la operacion del cliente y recolectar datos para configurar el SaaS.

### Duracion
60 minutos.

### Estructura

Minutos 0-5 - Bienvenida
- Agradecer la confianza.
- Explicar el objetivo de la llamada.
- Acordar agenda.

Minutos 5-20 - Diagnostico
Preguntas:
- Cuantos equipos manejas por torneo?
- Cuantas categorias?
- Cuantos arbitros?
- Cuantas canchas?
- Cuanto cobras de inscripcion, arbitraje y cancha?
- Como cobras hoy? (efectivo, transferencia, mixto)
- Cual es tu tasa de morosidad actual?
- Como aplicas sanciones?
- Cuanto tiempo dedicas a administrar?
- Cual es tu mayor dolor hoy?

Minutos 20-40 - Demostracion guiada
- Mostrar panel del admin.
- Mostrar como se registra un equipo.
- Mostrar como se programa un partido.
- Mostrar como se cierra un acta.
- Mostrar como se ejecuta una fianza.

Minutos 40-55 - Plan de configuracion
- Definir fecha de inicio del torneo.
- Definir categorias.
- Definir reglas.
- Definir conceptos de cobro.
- Definir politica de fianza.
- Agendar proxima sesion.

Minutos 55-60 - Cierre
- Resumir acuerdos.
- Enviar resumen por correo.
- Agendar siguiente sesion.

## 6. Guion de Capacitacion al Admin

### Duracion
60 minutos.

### Estructura

Minutos 0-10 - Repaso general
- Navegacion basica.
- Roles y permisos.
- Menu principal.

Minutos 10-30 - Operacion diaria
- Crear y aprobar equipos.
- Validar jugadores.
- Programar partidos.
- Cerrar actas.
- Aplicar sanciones.

Minutos 30-45 - Finanzas
- Configurar conceptos de cobro.
- Revisar saldos.
- Ejecutar fianzas.
- Procesar pagos.
- Revisar reportes.

Minutos 45-55 - Excepciones
- Manejar disputas.
- Corregir actas.
- Ajustar programacion.
- Resolver bloqueos.

Minutos 55-60 - Cierre
- Preguntas.
- Recursos de soporte.
- Proximos pasos.

## 7. Guion de Capacitacion a Delegados

### Duracion
45 minutos.

### Estructura

Minutos 0-10 - Introduccion
- Que es el SaaS.
- Como acceder.
- Roles.

Minutos 10-30 - Uso diario
- Inscribir equipo.
- Registrar jugadores.
- Ver calendario.
- Consultar tabla.
- Pagar cuotas.
- Ver estado de fianza.

Minutos 30-40 - Situaciones comunes
- Como agregar un jugador.
- Como cambiar un jugador de equipo.
- Como revisar sanciones.
- Como abrir una disputa.

Minutos 40-45 - Cierre
- Preguntas.
- Recursos.

## 8. Guion de Capacitacion a Arbitros

### Duracion
60 minutos.

### Estructura

Minutos 0-10 - Introduccion
- Que es el SaaS.
- Como acceder desde movil.
- PWA y modo offline.

Minutos 10-35 - Operacion en cancha
- Ver designaciones.
- Abrir acta.
- Escanear QR.
- Validar elegibilidad.
- Registrar eventos.
- Cerrar acta.

Minutos 35-50 - Situaciones especiales
- Sin internet.
- Jugador no elegible.
- Incidencia grave.
- Partido suspendido.

Minutos 50-60 - Cierre
- Preguntas.
- Contacto de soporte.

## 10. Metricas de Onboarding

| Metrica | Objetivo |
|---|---|
| Tiempo total de onboarding | <5 dias habiles |
| Sesiones de capacitacion | 3 (admin, delegados, arbitros) |
| Adopcion del admin (uso diario) | >80% en primera semana |
| Adopcion de delegados | >70% en primera semana |
| Adopcion de arbitros | >90% en primera semana |
| Primer partido operado completo | <7 dias |
| Satisfaccion del cliente (NPS) | >50 |

## 11. Costos de Onboarding

### Fase 1 (primeros 20 clientes)
- Sin costo adicional (incluido en el plan).
- Tiempo del fundador: 8-10 horas por cliente.

### Fase 2 (clientes 21-50)
- Onboarding asistido: incluido en Pro y Enterprise.
- Onboarding premium: $5,000 MXN (opcional).

### Fase 3 (clientes 51+)
- Onboarding self-service con videos.
- Onboarding asistido solo en Enterprise.

## 12. Casos Especiales

### Cliente con sistema previo
- Importar datos desde Excel.
- Mapear categorias y equipos.
- Validar con el cliente antes de migrar.

### Cliente con multiples complejos
- Configurar organizacion con jerarquia.
- Definir permisos por complejo.
- Capacitacion por separado por sede.

### Cliente que cambia de opinion a mitad del onboarding
- Detener proceso.
- Documentar motivo.
- Ofrecer ajuste o cancelacion.
- No forzar.

### Cliente que no completa la carga de datos
- Enviar recordatorios.
- Ofrecer asistencia adicional.
- Si no hay respuesta en 2 semanas, pausar onboarding.

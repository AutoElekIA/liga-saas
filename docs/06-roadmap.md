El proyecto avanza en 5 oleadas. Cada oleada tiene entregables claros y no se pasa a la siguiente hasta cerrar la anterior.

## Reglas del Roadmap

1. No se pasa de oleada sin cerrar la anterior.
2. No se construye un módulo sin sus dependencias listas.
3. No se vende ni se muestra el producto antes del MVP.
4. La Liga Cero alimenta el diseño, no se vende.
5. Los pilotos son gratuitos y con NDA.
6. Cada entregable vive en GitHub y es auditable.

## Reglas del Roadmap

1. No se pasa de oleada sin cerrar la anterior.
2. No se construye un modulo sin sus dependencias listas.
3. No se vende ni se muestra el producto antes del MVP.
4. La Liga Cero alimenta el diseno, no se vende.
5. Los pilotos son gratuitos y con NDA.
6. Cada entregable vive en GitHub y es auditable.

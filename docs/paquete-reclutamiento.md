## 4. Guion de entrevista (45 min)

### Minutos 0-5 - Apertura
"Gracias por el interes. Soy [tu nombre], fundador del proyecto. Te cuento brevemente de que se trata y luego me cuentas de ti."

### Minutos 5-20 - Experiencia tecnica
1. Cuentame de tu experiencia con Node.js y TypeScript.
2. Has trabajado con NestJS? Que tal te parecio?
3. Que experiencia tienes con PostgreSQL?
4. Has implementado Row-Level Security o algun sistema multi-tenant?
5. Has trabajado con PWA y offline?
6. Como manejas migraciones de base de datos?
7. Has integrado pasarelas de pago?

### Minutos 20-30 - Forma de trabajo
1. Como trabajas con Git y PRs?
2. Como estimas tareas?
3. Que haces cuando no entiendes algo?
4. Has trabajado en equipos distribuidos?
5. Cual es tu disponibilidad real semanal?

### Minutos 30-40 - Proyecto
1. Que te parece el proyecto?
2. Que preguntas tienes sobre el stack o alcance?
3. Cuanto tiempo crees que tomaria el MVP?
4. Que riesgos ves?
5. Como abordarias el primer sprint?

### Minutos 40-45 - Cierre
"Cual es tu expectativa economica? Puedes firmar NDA y cesion de derechos? Cuando podrias empezar?"

## 5. Criterios de decision

### Senales verdes
- GitHub activo con proyectos reales
- Experiencia demostrable con SaaS
- Preguntas inteligentes sobre el proyecto
- Acepta NDA y cesion sin dudar
- Disponibilidad clara y compatible
- Expectativa economica en rango

### Senales amarillas
- Cambia de stack con frecuencia
- No puede dar referencias
- No tiene claro su disponibilidad
- Tiene otros proyectos en paralelo sin transparencia

### Senales rojas (descartar)
- No acepta firmar NDA
- No acepta cesion de derechos
- No tiene GitHub activo
- Pide pago 100% por adelantado
- Presiona para cerrar rapido
- No puede explicar proyectos previos
